# 产品判断入口

更新时间：2026-11-03。职责：帮助 agent 做局部取舍，不新增用户需求。

用户希望通过双语阅读、朗读、查词积累和复习学习英语。目标、用户条件与完整验收在 [产品规格](product-specs/index.md)，选择理由在 [决定](../BilingualAuditor-docs/docs/decisions.md)；本页不重列功能合同。

实现取舍时：

1. 优先让当前一个小功能可以被手机验证，按 D09 的顺序推进；不一次引入整套账号、支付、云同步或多种复杂架构。
2. 先保证原文完整、失败可理解和已有进度不丢失，再优化动画与排版。
3. 向用户解释影响范围的选择。服务商、词典许可、备份覆盖和复习队列的未决问题在实施对应功能前收口，不阻塞无关的文档或本地核查。
4. 已确认需求与待评估技术分开。出现“规格需要但代码没有”时记录差距，不能倒过来缩减规格。
5. 不把尚未查证的收费、离线、设备可用性或教学效果写进产品承诺；当前状态见 [current-state](product/current-state.md)。
