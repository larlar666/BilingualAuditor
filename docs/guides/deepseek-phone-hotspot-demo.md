更新时间：2026-11-13。适用 [已批准的独立 ¥3／20 次计划](../plans/active/deepseek-phone-hotspot-demo.md)。后端／启动器独立安全评审已通过；本次本人手机已回报 health 成功、错误 pin 拒绝／恢复、一条中文翻译及原英文保留、纯英文原样显示，电脑同账本复核纯英文未增认领。完整质量及其余手机边界仍待人工验收；当前最小任务结束，不再新增请求或检查，代理窗口按本人试用保持运行，最多两小时自动截止。本人只开一个代理窗口，换端口双开不保证跨进程单请求；共享账本仍限制总预算。只用公开或自写短文，不把 Key 发到聊天。

## 1. 手动安装手机 App

电脑文件：`C:\Users\a1234\Documents\BilingualAuditor\app\build\outputs\apk\debug\app-debug.apk`。通过本人选用的文件传输方式发送到手机，手机文件管理器打开 APK，按系统提示仅为该来源允许安装；装好可关闭该来源的安装权限。此步骤无需 USB／ADB。版本必须对应 [主证据 APK 指纹](../evidence/deepseek-phone-hotspot-demo.md#android-自动检查)，安装成功不代表网络已通。

## 2. 让电脑连接这部手机热点

手机开热点，电脑连接它。当前观察：电脑 WLAN 为 `10.251.239.59`，手机网关为 `10.251.239.220`；重新连接可能变化，启动窗口显示的当次地址才有效。不能选普通路由器、VPN 或其他热点。不要关闭全部防火墙；启动器只展示审阅范围，不自动改防火墙。如需规则，应限定实际 Node 程序、当次 Wi-Fi、入站 TCP 8765、本地电脑 IP、远端仅手机 IP；系统的“所有网络”宽授权不适用，取消后再定位窄规则。

## 3. 在电脑打开临时窗口

使用 **PowerShell 7.5 或以上，STA 模式**，在项目目录运行。不传网卡／地址覆盖参数，由窗口列出实际热点并确认。以下首次命令已在 2026-11-13 正式执行，**不要再次初始化**。首次新账本只执行一次：

```powershell
pwsh -STA -NoProfile -File .\server\deepseek-phone-proxy\tools\start-phone-proxy.ps1 -RunProxy -CnyAccountConfirmed -InitializePhoneLedger
```

以后继续同一试验，去掉初始化参数：

```powershell
pwsh -STA -NoProfile -File .\server\deepseek-phone-proxy\tools\start-phone-proxy.ps1 -RunProxy -CnyAccountConfirmed
```

在“确认本人手机热点”窗口选择实际 WLAN，核对电脑地址及手机网关，点击“确认网关是本人手机”。若账本缺失、初始化残留、证明过期或校验失败，停下检查，不删文件、不重复初始化、不改日期续额度。

在掩码窗口分别填 DeepSeek 官方 API Key 和**已有个人代理 Bearer 凭证**，点击“启动已批准的临时代理”。不重新生成凭证；手机不能填供应商 Key。保留窗口，等待就绪，记录窗口给出的完整 HTTPS 地址和证书 SHA-256 指纹；就绪只证明本机启动，不证明手机或模型可用。

## 4. 手机配对并先检查连接

打开 App →“配置试用翻译服务”→ 将模式切至“临时电脑 DeepSeek 代理”。填窗口的完整地址（当前示例 `https://10.251.239.59:8765/translate`）、已有 Bearer、64 位十六进制证书指纹，再“应用配置”。不安装系统根证书，不绕过证书检查。

点“检查连接（不调用模型）”。成功应显示连接状态、认领次数和预留余额；**health 不验证 Key、官方网络或翻译质量**。先故意改一位指纹，检查应失败，再恢复正确指纹；这两次检查都不得增加模型次数或预算。若连接失败，先核地址、pin、设备时间、热点与窄防火墙，不用反复点击翻译排查。

## 5. 少量翻译与验收

先用短的公开／自写中文和混合英文段落，点击翻译一次，对照原英文拼写、大小写、URL、片段内部空白及整体自然度。手动重试也占一次且不退款。纯英文应本地原样显示且次数不增；不要为试验边界连续发 20 次真实请求。

离线边界清单：1000 码点允许、1001 码点提示超限并禁提交；emoji 按 Unicode 码点计。20 次／¥3 耗尽后拒绝外发，关闭再启动不恢复额度；这些以隔离账本自动测试核对，正式账本绝不重置。真机还要检查超限提示、错误 pin、健康检查零计费、断网、停止与英文自然度，并把结果记入 [主证据](../evidence/deepseek-phone-hotspot-demo.md)。

## 6. 停止及下次继续

点电脑窗口“停止并关闭”或关闭窗口即停止临时代理；会话最多两小时，不安装后台任务。App 取消不能撤回已经送出的收费请求。保留新 SQLite 和初始化标记；原四样本 ¥1 账本也保留。下次启动生成新证书，必须用新指纹重新配对；预算继续累计。App 配置仅内存保存，进程终止后重新填写；本机内存释放不等于可证明物理内存擦除。
