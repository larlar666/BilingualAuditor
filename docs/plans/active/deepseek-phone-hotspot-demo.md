更新时间：2026-11-13。状态：**human_acceptance_required**。用户已批准本轮范围并要求继续；该状态不是人工验收通过。Azure 保持人工暂停，不部署 Cloudflare。旧四样本试验已结束，独立 [¥1 计划](deepseek-translation-trial.md) 与账本不改、不重置。

## 范围与边界

手机 App → 电脑临时 HTTPS 代理 → DeepSeek 官方固定端点；电脑连接这部手机的热点，仅本人手机可用。只用公开或自写短文，保留原有英文内容、拼写和大小写，纯英文在 App 原样展示，不发模型请求。通用产品一万码点上限不变；本模式每次最多 **1000 Unicode 码点**，包含空白、标点和 emoji，不截断或拆分。

这是独立新增的 **CNY ¥3** 试验：最多 **20 次上游尝试或 ¥3 预留先到停止**；每次外发前持久原子预留 ¥0.15。失败、超时及手动重试也计数，不退款，不因跨日、重启或策略续核重置。无自动重试、自动切换或双发；同一 request UUID 不重放外发。预留不是平台账单、API 余额，也不能约束其他客户端消费。

已有 Bearer 访问凭证复用、不生成或更换；DeepSeek Key 只在电脑掩码窗口输入并在进程内使用，不进手机、文件、日志、argv 或环境。TLS 临时自签证书仅内存生成，手机配对 leaf DER 的 SHA-256 指纹；只绑定已选私有 IPv4，来源仅允许手机网关的精确 IPv4。临时窗口关闭即停，无后台服务，最长两小时。停止／取消只能中止后续处理，不能撤回已经外发的计费。
