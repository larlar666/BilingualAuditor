## 允许范围与非目标

允许：阅读页状态、翻译客户端、10,000 码点策略、本人试用的运行时服务配置、Worker 受控代理、鉴权、服务端长度/频率/持久预算限制、必要测试及受影响 owner 文档。

## 前后端合同与实现约束

1. App 在运行时配置完整 HTTPS `/translate` 地址和本人访问凭证；此凭证不是 Azure 服务密钥。首轮配置只保留在 ViewModel 内存，重开应用需重新填写，不作为持久设置或文段保存。手机长期路线的服务商密钥仍保存在服务端 Secret，不进入 APK、仓库、备份或日志；本机排查的掩码内存输入例外见 SECURITY。
2. `POST /translate`，JSON 为 `{text, requestId}`，使用 `Authorization: Bearer …`。成功返回 `{requestId, translation}`，译文为纯文本；失败返回 `{error: {code, message}}`。客户端使用安全错误映射，不直接显示上游响应正文。
3. 错误类别包括输入无效、文段过长、未授权、限流、额度耗尽、服务不可用、上游超时/失败及英文保留校验失败。拒绝不安全地址/重定向，限制请求和响应大小，不无限自动重试。
4. 原文、译文上下显示；翻译中防重复提交。请求绑定原文快照与配置版本，编辑、换文件或配置变更后旧结果不得覆盖当前内容，旧译文明确标记过期。
5. Azure HTML `notranslate`/`translate="no"` 仅是英文保护手段候选：输入转义、标记完整性、原英文还原/核验及解析失败都需处理。当前实现方向为限定 `div`/`span` 标记的严格解析和英文逐字校验，不依赖外部 HTML 解析包；真实 Azure 兼容性尚未验证。校验失败明确报错；真实请求样本通过后才能宣称满足 D10。
6. 本人首轮使用单个可轮换撤销凭证；D1 同一持久预算行承担该唯一调用者与总体限制。授权、长度、请求频率与原子预算预留全部发生在上游调用之前；缺配置或预算存储故障时拒绝放行。
7. 业务码点上限与上游计费预算分开。按最终发送的 HTML payload 使用保守计数并核对上游请求上限；预留后上游超时等不确定结果不自动返还额度。频率与预算具体数值属于实现默认，须记录并测试，不冒充用户单独决定。
8. 超限弹窗触发时机/频次属于实施默认，避免逐键重复打断；文件夹建议只是组织方向，不解除文段长度限制，不冒充已实现能力。

首轮已知限制：极端中英逐字交替可使保护 HTML 包装超出上游安全界，即使原文未超 10,000 码点也会明确返回 `PROTECTION_LIMIT`；不截断、不提供拆短建议。内部请求批处理及整篇一致性留待后续方案，不将此分支冒充全部合规长度材料均可翻译。

## 验收与停止条件

- 长度边界 9,999／10,000／10,001 码点，包含 emoji、空白和标点；导入安全上限与业务上限分别验证。
- 中文、混合句、完整英文句子、缩写、URL、大小写与原有错误拼写；纯英文不发送翻译请求。真实样本人工评判自然度和意思是否忠实。
- 空输入、重复点击、超限后恢复、请求中编辑/换文件/变更配置、失败保留原文及旧译文过期。
- 模拟断网、超时、授权失败、429、403001、上游异常和保护标记损坏；模拟通过不替代真实联网验证。
- 用真实本地存储验证预算并发及原子预留，证明存储失效/用尽后不调用上游；不能以 mock 或进程计数替代。
- 未满足免费条件、账户资格、部署域名可达性或英文保护门槛时，记录原因并停止对应在线步骤，不自动换付费层。
