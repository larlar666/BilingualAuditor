# 双语阅读与词汇复习：第一版产品需求 v0.1

状态：核心范围已确认，形成第一版产品基线；配套交互建议和技术选型仍可调整。规格基线：2026-10-21；阅读路径整理：2026-11-03。

本文区分「已确认需求」「建议默认值」「待决策事项」。建议不代表用户已经同意；未选定的服务和算法不代表已经实现。本文是“应该怎样”的主落点，当前能力及验证分别查 [current-state](../../docs/product/current-state.md) 和 [QUALITY_SCORE](../../docs/QUALITY_SCORE.md)。

## 1. 产品目标与使用者

帮助希望通过双语材料学习英语的用户，将复制的文段变成可对照阅读、可朗读、可积累词汇和复习的学习内容。

开发者为有一定基础、仍在学习的计算机科学与技术学生。开发过程需要解释关键概念、实现理由、验证方法和 Codex 使用技巧，按可运行的小步骤推进。

首批供开发者及小范围其他用户使用。首台测试设备为 vivo S30 Pro mini，用户表示可使用 Google Play；其他使用者的设备和 Google 服务可用性未知，不据此承诺全部设备兼容。第一版仅使用免费额度，后续可探索付费功能，暂不设计支付或订阅。

## 2. 已确认的需求

- 目标形态为 Android 应用，可安装 APK。
- 应用图标采用用户确认的粉蓝双色、中文 / ENG、耳机笑脸人物设计（D11）。
- 第一版以中文材料为主：输入/粘贴或打开 TXT，联网生成英文并对照阅读。TXT 导入接受中文、英文和中英混合；中英混合按中文到英文方向处理，原有英文保留（见 D10）。
- 单词本与复习可离线使用，已保存的释义和上下文不依赖重新联网查询。
- 提供中文和英文朗读、播放控制。
- 在设置页提供英式、美式发音选项；设备是否具备对应语音需要检测。
- 阅读时可以选词并加入单词本，查看释义。
- 提供自动推荐积累词汇的能力；低、中、高表示推荐数量由少到多，不表示词汇难度等级。
- 希望能够方便地批量加入推荐词，并探索拖入单词本的交互。
- 推荐词先预选，用户可取消部分词，确认后才加入单词本。
- 低 / 中 / 高最多推荐 3 / 6 / 10 个词；第一版先支持点选与批量确认，拖拽延后。
- 单词本采用 FSRS 安排复习，反馈为「忘记、困难、良好、简单」。具体库需评估成熟度、兼容性和许可证。
- 本地保存学习数据，支持手动导出 / 导入备份。
- 保存完整阅读历史，支持重新打开、手动删除，并纳入备份。
- 界面先简化实现，后续根据用户绘制的草图调整。

## 3. 核心流程

```text
输入或粘贴材料 → 翻译 → 双语对照与朗读
                           ↓
                 查询单词 / 查看推荐词
                           ↓
                     加入单词本
                           ↓
                  查看到期词 → 回忆 → 评分
```

当前优先让一篇中文文段贯通整个流程。D01～D08 已确认，完整决定见决策记录。核心范围不再等待首轮产品选择；服务、库与配套交互建议不等于已经核实或实现。

## 4. 第一版功能范围与交互说明

本节核心能力来自已确认需求；明确标注「建议」的细节可在实现与草图讨论时调整，无需把它们误记为用户已确认。

### 4.1 阅读页

- 提供多行输入、显式粘贴按钮、编辑和翻译按钮。
- TXT 导入支持中文、英文及中英混合。中英混合输出统一为英文，翻译中文部分，保留原有英文内容、拼写和大小写，不将英文翻成中文或擅自纠错；不能仅凭服务返回成功判定符合此规则，实现状态查 current-state。
- 保留原文；用户修改原文后重新翻译，旧译文标记为需要更新。
- 原文、译文以简易的上下排列呈现；后续按草图调整。
- 为中文和英文分别提供朗读及停止；开始另一段时停止当前朗读，避免重叠。
- 先实现整段播放；分句定位、暂停续播和逐词跟读作为后续候选。
- 英文单词可点击查询，在释义面板中加入单词本。
- 输入为空时提示输入；翻译中显示进度状态，避免重复提交。
- 翻译失败保留输入，给出原因和重试入口，不把失败文本当成成功译文。
- 无网络时提示翻译需要联网，不影响进入单词本和复习已保存的内容。
- 不默认在后台读取剪贴板。系统分享接收入口列为后续候选。

### 4.2 词典与单词本

- 显示查询词、可用释义；音标和词性在数据源支持时显示。
- 保存词条标识、词形还原结果（如数据源支持）、用户选择的释义、来源原句及其译文。
- 单词发音先调用系统 TTS，不默认包含词典真人录音。
- 重复加入同一词条时提示已存在，不重复创建学习卡片或重置复习进度。
- 查询不到释义时明确提示，允许稍后重试；不生成看似来自词典的虚构释义。
- 单词本先提供列表、搜索、详情和删除；建议删除前确认，批量删除明确影响范围。
- 单词及其上下文独立保存，完整原文与译文同时保存在阅读历史中。

### 4.3 自动推荐词

- 提供低、中、高三个数量档位。
- 已确认上限为低 3、中 6、高 10 个，指每次推荐中的不同候选词数；短文不凑数。后续可根据试用调整参数。
- 自动推荐词先从本次生成的英文译文中选取。英文 TXT 可导入，不等于已完成纯英文材料的推荐词流程；英文到中文翻译仍不在第一版范围。
- 排除标点和常见功能词，尽量合并词形变化；已在单词本的词不重复新增。
- 第一版可采用常见词频和文中重复情况排序；不声称已经判断用户实际水平。
- 展示预选推荐词，允许取消部分词；点击确认后才批量加入，不在翻译完成时自动入库。
- 建议展示本次加入结果，并允许撤销该批次新增项。
- 第一版实现点选与批量确认；拖拽交互已明确延后，不作为第一版验收要求。

### 4.4 复习

- 显示到期词数量；新词与到期复习词的安排在开发复习模块前确认。
- 卡片先显示英文词及辅助原句，中文释义需主动点击后展示。
- 用户查看答案后评分，应用保存本次记录并更新下次复习时间。
- 重启应用后保留进度；没有到期卡片时显示空状态。
- 使用 FSRS，评分为「忘记、困难、良好、简单」；不混用固定间隔规则。
- 在选定具体库前评估维护情况、许可证、Android 兼容性和可复现的调度测试；选库未完成不声称 FSRS 已实现。
- 保存复习事件时间、评分及恢复调度所需的卡片状态，记录算法版本与相关设置，避免只保存下次日期。
- 第一版建议采用所选实现的合理默认参数，不承诺在少量数据下已经完成个性化训练；关键参数在实施时记录。
- 推送提醒、每日目标、学习统计暂作为后续候选。

### 4.5 设置

- 英语口音：美式 / 英式，保存用户选择。
- 语速：可调并支持试听；中文与英文是否分别设置可在草图阶段决定。
- 显示语音不可用状态，提供合理指引；不静默忽略用户口音选择。
- 推荐词数量档位可调整。

### 4.6 备份与恢复

- 提供手动导出 / 导入入口，用户选择文件位置；不要求注册账号或云同步。
- 导出范围包含单词、所选释义、来源上下文、复习日志、FSRS 状态、相关设置，以及完整阅读历史（原文与译文）。
- 建议备份文件带格式版本，以便未来升级时识别兼容性；不包含服务密钥、设备凭证或无关日志。
- 建议先采用「确认后整体恢复」，避免第一版合并两套 FSRS 日志造成调度不一致；导入前说明覆盖范围并允许先备份现有数据。
- 导入前检查结构和版本；失败时保留原有数据，成功后词条和复习进度一致。
- 提醒用户：卸载 / 清除应用数据可能丢失本机内容，备份应保存到应用私有目录以外。备份可能包含私人原文，需要妥善保管。

### 4.7 免费额度与小范围试用（处理规则建议）

- 仅选择符合免费额度和使用许可的服务；免费额度的有效期、实名 / 绑卡条件、限流和用尽后行为须实际核对。
- 不默认启用超额付费；服务支持时设置硬限额或禁用自动扣费。无法避免意外费用的方案不作为默认选择。
- 应用请求失败时区分断网、服务暂不可用和额度 / 限流问题，保留原文，不无限自动重试。
- 额度用尽时停止对应在线操作并提示；本地单词本、复习和备份仍可用。
- 如采用共享后端，需有基本访问控制、每用户 / 每设备用量限制及总体上限；第一版不一定需要完整账号体系，授权方式待技术评估。
- 免费翻译额度不代表后端托管也免费，后端免费层条件应单独核对。

### 4.8 阅读历史

- 保存完整中文原文与成功生成的英文译文，支持列表、重新打开和手动删除。
- 已保存内容在断网时仍可查看；重新翻译需要联网，朗读是否能离线由语音引擎决定。
- 建议每次成功翻译后自动保存，记录时间及关联的原文 / 译文快照；失败不生成一条看似翻译成功的历史。
- 建议先将历史记录作为不可直接覆盖的快照；重新编辑、成功翻译后另存一条，避免旧词卡上下文随之变化。
- 建议删除前确认；删除历史仅删除该阅读记录，不连带删除已加入的单词、单词上下文或复习记录。
- 建议删除单词同样不删除原阅读历史。两个入口的删除影响范围需在界面说明。
- 历史记录随备份导出 / 导入；不上传云端同步。备份中的副本不因应用内删除而自动消失。

## 5. 服务、数据和隐私约束

- 已选择联网翻译，当前预算仅免费额度；具体服务商和后端部署方式尚待评估。翻译服务不保证纠错或译文准确。
- 不自动改写或覆盖用户原文，纠错功能暂作为后续候选。
- 系统 TTS 为首选技术候选；实际离线能力由所选引擎和语音数据决定，需设备验证。
- 本地词库与在线词典均需检查数据覆盖和许可，包括小范围分发、释义本地保存及导出备份是否允许。不能持久保存学习所需释义的数据源不符合当前离线复习目标。牛津词典是待评估候选，尚未确认可用接口或授权。
- 使用在线服务时，明确哪些文本会发送给哪个服务；不能宣称完全离线。
- 不将服务商长期密钥写入 APK、Git、文档或日志；云服务如需密钥，采用受控后端或服务商支持的安全授权方案。
- 单词本和复习数据在本机持久保存；离线可查看已保存释义、来源原句和复习记录。首次查词能否离线取决于后续词典选择，不能与已保存词条离线可用混为一谈。
- 手动备份已确认；账号与云同步暂未纳入，未来收费是可能方向，不属于第一版已确认功能。

## 6. 第一版验收清单（随决策更新）

- [ ] 用户输入一段中文材料后，联网获得英文译文，原文保持可见和可编辑。
- [ ] 中文、英文及混合 UTF-8 TXT 均能完整导入；混合文本生成英文时原有英文不被翻译或改写，英文句子、大小写、缩写和英文链接分别验收。
- [ ] 空输入、加载、成功和失败状态均可识别，失败后可以重试。
- [ ] 在支持的设备和语音引擎上，中英文分别能播放和停止。
- [ ] 切换英式 / 美式设置后被持久保存，播放时请求对应语音；缺失时提示。
- [ ] 用户可从英文内容查询词义并加入单词本，包含来源上下文。
- [ ] 对同一词重复加入，不产生重复卡片或丢失既有学习进度。
- [ ] 同一材料的低 / 中 / 高推荐分别不超过 3 / 6 / 10 个不同候选词；可选词不足时数量减少。
- [ ] 翻译完成后没有未经确认的新词入库；取消预选后，确认只加入最终选中的词。
- [ ] 建议验收：用户能看清加入结果并撤销本次新增。
- [ ] 重启应用后，单词、设置和复习记录仍存在。
- [ ] 按选定 FSRS 实现安排到期复习，四档评分后更新状态和下次时间；离线可完成该流程。
- [ ] 导出后在空白测试数据环境导入，词条、上下文、复习日志和 FSRS 状态得到恢复。
- [ ] 导入不支持 / 损坏的文件时提示错误，原有数据保持完整。
- [ ] 重启后可从历史重新打开完整原文与译文；断网时也可查看，无需重新请求翻译。
- [ ] 用户可手动删除阅读历史；建议验收：删除后已收藏单词及其上下文和复习进度仍保留。
- [ ] 导出并恢复后，完整阅读历史也得到恢复。
- [ ] 建议验收：模拟免费额度用尽或限流时，在线操作给出明确提示，本地学习仍可用。
- [ ] 断网时翻译提示需要联网；已保存单词的释义、上下文和复习功能仍可用。
- [ ] 如需下载词典或语音，明确提示下载及其用途；朗读离线能力单独按设备验证。

构建成功不能替代翻译、语音和触摸交互的设备验证。尚未执行的验证必须标记为待验证。
